# GLiNER test fixtures

Self-contained assets for testing the local (on-device) GLiNER inference path
(`Phileas.Filters.PhEye.GlinerModel`) in default CI, without the production model
(`philterd/ph-eye-pii-base`, 183 MB int8 / 611 MB fp32, too large to vendor).

| File | Size | Purpose | Provenance |
|------|------|---------|------------|
| `spm.model` | ~2.4 MB | deberta-v3 SentencePiece tokenizer | Copied verbatim from `philterd/ph-eye-pii-base`. |
| `tokenizer_parity.json` | ~4 KB | Golden input→token-id pairs | Generated by `generate_tokenizer_fixture.py`. |
| `model.onnx` | ~2 KB | Synthetic mock GLiNER graph | Generated by `generate_onnx_fixture.py`. |
| `gliner_config.json` | <1 KB | Minimal config for the fixture model | Hand-authored; mirrors the real config's `max_width`/`class_token_index`/`max_len`. |

Together `model.onnx` + `gliner_config.json` + `spm.model` form a valid GLiNER model
directory that `GlinerModel(modelPath)` loads directly.

## Which test uses what

- **`GlinerTokenizerParityTests`** (issue #309): asserts the .NET `SentencePieceTokenizer`
  reproduces the Python `sentencepiece` ids in `tokenizer_parity.json`, token-for-token.
- **`GlinerFixtureModelTests`** (issue #308): runs `GlinerModel` end to end against this
  directory, exercising a real `InferenceSession.Run` and the decode.
- **`GlinerModelTests`** (`[ModelFact]`): real-weight parity against `ph-eye-pii-base`; gated
  behind `PHILEAS_GLINER_MODEL_DIR` and skipped when it is unset.

## The synthetic ONNX graph (`model.onnx`)

`model.onnx` is a hand-built graph with the exact GLiNER markerV0 signature (six inputs;
`logits[1, num_words, max_width, num_labels]` output), **not** an export of the real model.
It returns deterministic logits — the two-word span (word 0..1, label 0) at +10 and the
single-word span it contains at +6, non-firing everywhere else — so on a ≥2-word input the
greedy non-overlapping decode keeps the wider span and drops the contained one. This verifies
the C# tensor feed/fetch wiring and the decode (threshold, span→offset, label selection, and
overlap resolution) against a known graph; real-weight parity stays in the gated
`GlinerModelTests`. See `generate_onnx_fixture.py` for the full construction and the
determinism rationale.

## Regenerating

```sh
pip install sentencepiece onnx          # onnxruntime optional, for local validation
python generate_tokenizer_fixture.py    # rewrites tokenizer_parity.json
python generate_onnx_fixture.py         # rewrites model.onnx
```

The generator scripts are source-only (not copied to the test output). No real data appears
in any fixture; every input string is synthetic.
